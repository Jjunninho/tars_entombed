# 🤖 TARS: Descida Infinita — Entombed Engine

O **TARS: Descida Infinita** é um projeto que une a estética de ficção científica moderna com algoritmos clássicos da era 8-bit. Utilizando uma recriação fiel do algoritmo de geração procedural do jogo *Entombed* (Atari 2600, 1982), o sistema gera um labirinto vertical infinito que desafia a integridade do robô TARS conforme ele mergulha em profundidades desconhecidas.

## 🚀 Funcionalidades e Diferenciais

- **Entombed Procedural Engine v2.0:** Implementação baseada na famosa "tabela de labirinto" do Atari, garantindo caminhos complexos e tecnicamente históricos.
- **Múltiplos Modos de Jogo:**
  - **Caminhada:** O modo padrão de exploração e descida.
  - **Asterisco:** Uma variação estética/funcional inspirada em caracteres de terminais antigos.
- **Níveis de Dificuldade:** Escolha entre Fácil, Normal, Difícil ou o **Modo Criativo** para exploração livre.
- **Sistema de Sementes (Seed):** Use sementes específicas para compartilhar labirintos ou competir no mesmo percurso com outros jogadores.
- **Mecânica de Jogo:** Controle a integridade do TARS enquanto desce. O jogador pode interagir com o cenário para limpar blocos e abrir caminho.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Canvas:** Renderização de alta performance para o labirinto infinito a 60 FPS.
- **Vanilla JavaScript:** Lógica central da engine de labirinto e física do personagem.
- **CSS3:** Interface minimalista e temática, inspirada em sistemas operacionais espaciais.

## 🕹️ Como Jogar

1. Acesse o [TARS: Descida Infinita](https://jjunninho.github.io/tars_entombed/).
2. **Movimentação:** Use as setas `(← →)` para mover e `(↑)` para pular.
3. **Alternar Modo:** Pressione `ESPAÇO` para trocar entre o modo Caminhada e Asterisco.
4. **Interação:** Use `L` para limpar blocos que bloqueiam seu caminho e `R` para reiniciar a descida.
5. **Desafio:** Veja quão profundo você consegue chegar antes de comprometer a integridade do sistema!
