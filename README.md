# 🤖 TARS: Descida Infinita — Entombed Engine

O **TARS: Descida Infinita** é um jogo infinito que une a estética de ficção científica moderna com algoritmos clássicos da era 8-bit. Utilizando uma recriação fiel do algoritmo de geração procedural Entombed, embarque em uma aventura de descida interminável através de labirintos gerados dinamicamente!

## 🎮 Jogue Agora!

**[▶️ Clique aqui para jogar TARS: Descida Infinita](https://jjunninho.github.io/tars_entombed/)**

O jogo está disponível no GitHub Pages e pronto para jogar diretamente no seu navegador — sem instalação necessária!

---

## 🚀 Funcionalidades e Diferenciais

- **Entombed Procedural Engine v2.0:** Implementação baseada na famosa "tabela de labirinto" do Atari, garantindo caminhos complexos e tecnicamente históricos.
  
- **Múltiplos Modos de Jogo:**
  - **Caminhada:** O modo padrão de exploração e descida contínua.
  - **Asterisco:** Uma variação estética/funcional inspirada em caracteres de terminais antigos.

- **Níveis de Dificuldade:** Escolha entre:
  - 🟢 **Fácil** - Para iniciantes
  - 🟡 **Normal** - O desafio padrão
  - 🔴 **Difícil** - Para veteranos
  - ✨ **Modo Criativo** - Exploração livre, sem limites

- **Sistema de Sementes (Seed):** Use sementes específicas para compartilhar labirintos ou competir no mesmo percurso com outros jogadores.

- **Mecânica de Jogo:** Controle a integridade do TARS enquanto desce através de labirintos infinitos. O jogador pode interagir com o cenário para limpar blocos e abrir caminho.

---

## 🎯 Como Jogar

1. **Acesse o jogo:** https://jjunninho.github.io/tars_entombed/
2. **Movimentação:** Use as setas `← →` para se mover e `↑` para pular
3. **Alternar Modo:** Pressione `ESPAÇO` para trocar entre o modo Caminhada e Asterisco
4. **Interação:** 
   - Pressione `L` para limpar blocos que bloqueiam seu caminho
   - Pressione `R` para reiniciar a descida
5. **Desafio:** Veja quão profundo você consegue chegar antes de comprometer a integridade do sistema!

## 📚 Sobre o Algoritmo Entombed

O Entombed é um clássico jogo de 1982 para o Atari que utilizava um algoritmo de geração procedural inovador para sua época. Este projeto reimplenta esse conceito com melhorias modernas, mantendo a essência do design clássico.
